# Security

## Reporting a vulnerability

Do not open a public issue for a security problem.

- **In IndexTables itself:** report it privately through "Report a vulnerability" on the Security tab of [indextables/indextables](https://github.com/indextables/indextables/security).
- **In this website:** report it the same way on the Security tab of this repository.

Include what you found, how to reproduce it and which version or commit it affects.

## Scope of this repository

This repository builds a static site. It holds no credentials and runs no server. Examples in the documentation use placeholders for keys and tokens; a real secret in a page or in the history is a vulnerability to report.
