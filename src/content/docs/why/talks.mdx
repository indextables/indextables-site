## Indexed and Full-Text Search in the Lakehouse

Scott Schenkein, the author of IndexTables, explains why retrieval on lakehouse tables is slow, how an index in object storage changes that, and how the pieces fit together. Published by Databricks Events on 26 June 2026.

### What has changed since the talk

The talk was recorded for IndexTables 0.5.x. Since then the engine has been rebuilt:

- The benchmark figures in the talk were measured on 0.5.x. Figures for the current version are not published yet.
- DataFusion is now a second supported engine beside Spark.
- Iceberg and Delta companions honour row-level deletes, and sync incrementally.
- Some settings and commands changed. See [Migrate from 0.5.x](/guides/migrate/from-0-5/).
