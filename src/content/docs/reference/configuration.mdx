Defaults and keys are still changing upstream, so this page is regenerated on every sync and is the only place the site states a default.

Keys are case-insensitive and are shown relative to `spark.indextables.`. An option on the operation overrides a table property in the log, then the session configuration, then `spark.indextables.*` in the Hadoop configuration. Credentials and credential-steering keys cannot be table properties.

**Process-scoped** keys are read once per JVM, from the Spark configuration at start-up; a later different value is ignored with a warning. A key with no default shown is unset unless you set it.
